[CS:S] Trouble in Terrorist Town (TTT) Framework

A modular Trouble in Terrorist Town (TTT) framework for Counter-Strike: Source. 
It features a robust core plugin handling role assignment, shop system, body inspection, karma/credits, and round resolution. All weapons and items are implemented as independent sub-plugins, making the framework highly customizable and easy to expand.

[ KNOWN BUGS & ISSUES ]
- Plugin Incompatibility: Some specific weapon/item sub-plugins may currently have compatibility issues with the TroubleInTerroristTown core plugin, which may cause errors or unexpected behavior.

[ REQUIREMENTS ]
- Game: Counter-Strike: Source (CS:S). (Not compatible with CS:GO/CS2).
- SourceMod: 1.12 or later.
- Extensions: sdktools, sdkhooks, cstrike, morecolors, vphysics.
- Dependencies: NoBlock (Required for the noblock management features to work properly).
